# Brain Tumor MRI Classification

## Overview
This project focuses on the classification of brain tumor MRI scans using deep learning techniques. The end-to-end implementation is contained within a single Google Colab notebook, encompassing everything from dataset preparation to model training and a final Gradio inference demonstration.

## Problem Statement
The classification task aims to categorize brain MRI scans into four distinct classes:
- glioma
- meningioma
- pituitary
- notumor

## Project Workflow
The implemented workflow includes the following high-level stages:
- dataset preparation
- exploratory analysis
- preprocessing
- augmentation
- data pipeline
- transfer learning
- model training
- evaluation
- model improvement
- final inference / Gradio demonstration

## Models
The project implements and evaluates the following architectures:
- VGG16
- MobileNetV2

## Results
Final quantitative results will be documented in a later repository update.

`notebooks/Brain_Tumor_MRI.ipynb`
